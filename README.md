# 消费边界账本

一个以“现在真正还能花多少”为中心的个人账本 PWA 原型。

## 本地运行

```bash
npm install
npm run dev
```

在浏览器打开终端显示的地址。数据保存在浏览器本地存储中。

## 主要功能

- 多账本：旧正式数据和已保存的测试数据自动迁移为独立账本，可创建、复制、重命名和切换
- 月生活预算与自定义预留，剩余预算自动计算
- 支出、收入、分类图标、愿望单和按周／月查看支出
- 向左滑动卡片，在右侧打开编辑或删除等操作；删除项目进入保留 30 天的垃圾桶
- Excel 支出导入导出，以及包含当前账本全部数据的 JSON 备份／恢复
- 动态均摊、固定日额、自定义餐别时间和月账期

目前没有自动跨设备同步。数据保存在当前浏览器，换设备前请在设置中导出完整备份，然后在另一设备导入。清除浏览器网站数据也会删除本地账本，建议定期备份。
